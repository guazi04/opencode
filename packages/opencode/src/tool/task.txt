Launch a new agent for complex, multistep work.

Available agent types and responsibilities:
{agents}

Required parameters:
- `description`: short summary (3-5 words)
- `prompt`: complete task instructions
- `subagent_type`: chosen agent type

Optional parameters:
- `task_id`: resume an existing task session
- `command`: command that triggered this task

Use this tool when executing custom slash commands; pass the slash invocation as the full prompt (arguments allowed), for example `Task(description="Check file", prompt="/check-file path/to/file.py")`.

Do not use this tool for direct file lookups in known paths/small scopes; use Read/Glob instead.
Do not use this tool for requests unrelated to available agent descriptions.

Usage notes:
1. Launch multiple agents in parallel when possible.
2. Agents return one result message; summarize it for the user.
3. Without `task_id`, each invocation starts a fresh context.
4. For fresh runs, include detailed instructions and required output format.
5. Explicitly state whether the agent should implement code or do research, and how to verify results.
6. Use proactively if an agent description indicates proactive use.
